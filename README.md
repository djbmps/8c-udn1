## โครงสร้างการเก็บข้อมูล

เก็บข้อมูล **2 ระดับ** ในไฟล์ Google Sheet เดียวกัน คนละแผ่นงาน

| แผ่นงาน | 1 แถวข้อมูลคือ | ผู้กรอก |
|---|---|---|
| `ระดับโรงเรียน` | 1 โรงเรียน / ปีการศึกษา / ภาคเรียน | ผู้รับผิดชอบของโรงเรียน (ผอ. / ครูวิชาการ) |
| `ระดับชั้น` | 1 ระดับชั้น (อ.1 – ม.3) ของโรงเรียนนั้น / ปีการศึกษา / ภาคเรียน | ครูประจำชั้น / ครูผู้สอน |

**คีย์ป้องกันข้อมูลซ้ำ** — `ปีการศึกษา + ภาคเรียน + โรงเรียน (+ ระดับชั้น)`
ถ้าส่งซ้ำด้วยคีย์เดิม ระบบจะ **ทับข้อมูลเดิม** และบันทึกเวลาแก้ไขล่าสุดไว้
โรงเรียนจึงแก้ไขข้อมูลของตนเองได้ตลอด โดยไม่เกิดแถวซ้ำ และรหัสอ้างอิงไม่เปลี่ยน

### คอลัมน์ในแต่ละแถว (30 คอลัมน์)

```
ลำดับ · วันที่บันทึก · แก้ไขล่าสุด · รหัสอ้างอิง
ปีการศึกษา · ภาคเรียน · อำเภอ · กลุ่มโรงเรียน · โรงเรียน
ขนาดโรงเรียน (หรือ ระดับชั้น) · จำนวนนักเรียนทั้งหมด · จำนวนที่ประเมิน
C1 · C2 · C3 · C4 · C5 · C6 · C7 · C8            ← คะแนนรูบริก 1–4
คะแนนเฉลี่ย 8C · ระดับคุณภาพ
จุดเด่น · จุดที่ควรพัฒนา · ลิงก์หลักฐาน
ผู้กรอกข้อมูล · ตำแหน่ง · เบอร์โทรศัพท์ · อีเมล/ID Line · หมายเหตุ
```

อำเภอถูกเติมให้อัตโนมัติจากชื่อกลุ่มโรงเรียน — ผู้กรอกไม่ต้องเลือกเอง

## เกณฑ์การประเมิน (รูบริก 4 ระดับ)

ให้คะแนนแต่ละ C จาก **ภาพรวมของผู้เรียนส่วนใหญ่** โดยใช้หลักฐานเชิงประจักษ์
เช่น ชิ้นงาน แบบบันทึกพฤติกรรม ผลการปฏิบัติ

| คะแนน | ระดับ | ความหมายโดยรวม |
|---|---|---|
| 1 | ควรพัฒนา | ทำได้เมื่อมีผู้กำกับใกล้ชิด ยังไม่แสดงทักษะด้วยตนเอง |
| 2 | พอใช้ | ทำได้ตามขั้นตอน/ตัวอย่างที่กำหนดให้ |
| 3 | ดี | ทำได้ด้วยตนเอง อธิบายเหตุผลและปรับใช้ได้ |
| 4 | ดีเยี่ยม | ทำได้เกินความคาดหวัง ต่อยอด/เผยแพร่ เป็นแบบอย่างแก่ผู้อื่น |

คำอธิบายรายด้านทั้ง 32 ข้อความ อยู่ในไฟล์ `rubric.js` และแสดงบนหน้าจอขณะกรอก
(ผู้ประเมินอ่านคำอธิบายแล้วเลือกได้ทันที ไม่ต้องเปิดเอกสารแยก)

**การแปลผลคะแนนเฉลี่ย 8C**

| ช่วงคะแนน | ระดับคุณภาพ |
|---|---|
| 3.51 – 4.00 | ดีเยี่ยม |
| 2.51 – 3.50 | ดี |
| 1.51 – 2.50 | พอใช้ |
| 1.00 – 1.50 | ควรพัฒนา |

## คุณสมบัติ

**หน้ากรอกข้อมูล (`index.html`)**

- เลือกระดับข้อมูล — ระดับโรงเรียน หรือ ระดับชั้น — ระบบสลับช่องกรอกให้อัตโนมัติ
- เลือกกลุ่มโรงเรียน แล้วรายชื่อโรงเรียนในกลุ่มแสดงให้เลือกทันที
- การ์ดรูบริก 8 ด้าน แสดงคำอธิบายครบทั้ง 4 ระดับ กดเลือกได้เลย
- แถบคะแนนสดติดขอบล่างจอ — เห็นค่าเฉลี่ยและระดับคุณภาพขณะประเมิน
- ตรวจสอบความถูกต้องทั้งฝั่งเว็บและฝั่งเซิร์ฟเวอร์ แสดงรหัสอ้างอิงเมื่อบันทึกสำเร็จ
- บันทึกซ้ำเพื่อแก้ไขข้อมูลเดิมได้ ไม่เกิดแถวซ้ำ
- รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

**แดชบอร์ด (`admin.html`)**

- เข้าระบบด้วยรหัสผ่าน จำสถานะไว้ระหว่างใช้งาน
- การ์ดสรุป 6 ตัว — จำนวนรายการ · ความครอบคลุมของโรงเรียน · คะแนนเฉลี่ย 8C ·
  จำนวนนักเรียนที่ประเมิน · ทักษะที่แข็งแรงที่สุด · ทักษะที่ควรเร่งพัฒนา
- กราฟคะแนนเฉลี่ยรายทักษะ 8 ด้าน (เรียงสูง→ต่ำ) รายอำเภอ และรายกลุ่มโรงเรียน
- กราฟการกระจายระดับคุณภาพจำแนกรายอำเภอ
- กราฟรายระดับชั้น (เมื่อดูข้อมูลระดับชั้น)
- ตัวกรอง — ระดับข้อมูล · ปีการศึกษา · ภาคเรียน · อำเภอ · กลุ่มโรงเรียน · ค้นหา
- ตารางข้อมูลเต็ม คลิกหัวตารางเพื่อเรียงลำดับ
- **รายชื่อโรงเรียนที่ยังไม่ส่งข้อมูล** แยกตามกลุ่ม — ใช้ติดตามได้ทันที
- ส่งออก CSV รองรับภาษาไทย เปิดใน Excel ได้ทันที และสั่งพิมพ์รายงานได้

ค่าเฉลี่ยทุกจุดในแดชบอร์ดเป็น **ค่าเฉลี่ยถ่วงน้ำหนักตามจำนวนนักเรียนที่ประเมิน**
โรงเรียนขนาดใหญ่จึงไม่ถูกนับเท่ากับโรงเรียนขนาดเล็กในภาพรวมของเขต

## การติดตั้งโดยย่อ

1. สร้าง Google Sheet เปล่า → คัดลอก ID จาก URL ช่วง `/d/......./edit`
2. นำ `Code.gs` ไปวางที่ [script.google.com](https://script.google.com) แก้ค่า 3 บรรทัดบนสุด
   (`SHEET_ID`, `ADMIN_PASS`, `OPEN_FOR_SUBMIT`)
3. Deploy เป็น **เว็บแอป (Web app)** โดยตั้ง
   **ดำเนินการในฐานะ: ฉัน (Me)** และ **ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone)**
4. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในตัวแปร `API_URL`
   ของทั้ง `index.html` และ `admin.html`

รายละเอียดทั้งหมดอยู่ใน [`คู่มือการติดตั้ง.md`](คู่มือการติดตั้ง.md)
